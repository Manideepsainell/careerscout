# CareerScout Roadmap

## Vision

Build a personal job discovery platform that reduces search time and helps identify the most relevant software engineering opportunities.

---

# V1 - Foundation

Status: Planning

Goal:

Collect, normalize, score, and display jobs in a single dashboard.

Features:

- Company management
- Job collection
- Job normalization
- Duplicate detection
- Rule-based scoring
- Dashboard
- Application tracking

Success Criteria:

- Jobs collected from supported sources
- Jobs scored automatically
- Dashboard displays ranked opportunities
- Daily search time reduced significantly

---

# V2 - Intelligence

Goal:

Improve ranking quality using historical outcomes.

Features:

- Interview history analysis
- Company watchlist
- Preference tuning
- Improved scoring logic

Success Criteria:

- Better ranking accuracy
- Faster identification of high-value opportunities

---

# V3 - Automation

Goal:

Reduce manual monitoring.

Features:

- Scheduled crawling
- Daily job digest
- New opening detection
- Watchlist alerts

Success Criteria:

- New opportunities surfaced automatically
- Less manual searching required

---

# V4 - Career Tracking

Goal:

Track the complete job search process.

Features:

- Application tracking
- Interview tracking
- Offer tracking
- Search analytics

Success Criteria:

- Complete visibility into job search progress

---

# Future Ideas

Potential additions:

- Resume fit analysis
- Application notes
- Company research dashboard
- Interview preparation support
- Market trend analysis

These are optional and should only be built if they solve a real problem.

---

# Development Principles

1. Build for actual usage.

2. Prefer simple solutions over complex ones.

3. Keep scoring explainable.

4. Avoid unnecessary AI dependencies.

5. Focus on reducing search time.

6. Optimize for opportunity quality, not application quantity.

7. Add complexity only when justified by real usage.

---

# Current Focus

Complete V1 before starting any V2 features.

Priority Order:

1. Data Model
2. Collectors
3. Normalization
4. Scoring Engine
5. Dashboard
6. Application Tracking
