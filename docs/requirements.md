# CareerScout Requirements

## Problem Statement

Current job search requires manually checking:

- LinkedIn
- Naukri
- Indeed
- Wellfound
- Company career pages

This causes:

- Duplicate effort
- Missed opportunities
- Time waste
- Poor prioritization

---

## Goal

CareerScout should:

1. Collect opportunities from multiple sources
2. Normalize job information
3. Score opportunities based on user preferences
4. Rank opportunities by relevance
5. Track applications
6. Surface the highest ROI jobs daily

---

## Success Metrics

### Primary

Reduce daily job-search time:

90+ minutes → 15–20 minutes

### Secondary

- More quality applications
- Fewer missed opportunities
- Faster identification of high-fit roles
